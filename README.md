Dreamcore Unity MVP Horror Skeleton - Tablet-ready Docker/Render Deployment

This final package consolidates the tablet-friendly deployment scaffold for Docker-based Render deployment. It includes: Dockerfile, nginx config, render manifest template, and instructions for producing Unity WebGL build and pushing to Render.

Usage:
- Produce a Unity WebGL build at Build/WebGL.
- Build the Docker image and push to Render or configure Render to build from repo.
- Use TabletUsage.md for tablet-specific guidance.
